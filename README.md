# THEMAN ALIVE choice

QR로 방문해 이름·MBTI·나이를 입력하고, 나와 매칭되는 배우의 결과를 확인하고 저장하는 한국어·중국어 모바일 웹사이트입니다.

## 실행

Node.js 20 이상을 사용합니다. 사이트 실행·빌드에는 패키지 설치나 API 키가 필요하지 않습니다.

```sh
npm run dev
```

로컬 주소: `http://127.0.0.1:4173`

```sh
npm test
npm run build
npm run preview
```

`dist/` 전체를 정적 호스팅에 업로드하면 됩니다. 서버·DB가 필요하지 않고, 하위 경로 배포도 지원합니다. `vercel.json`에는 테스트 통과 후 정적 파일을 배포하는 설정이 포함되어 있습니다.

## QR 연결 주소

실제 배포 주소 뒤에 아래 값을 사용합니다. QR 자체는 URL을 여는 역할만 합니다.

| 주소 | 진입 화면 |
| --- | --- |
| `/` 또는 `/?lang=ko` | 한국어 입력 화면 (기본) |
| `/?lang=zh` | 중국어 입력 화면 |
| `/?page=01` | 중국어 입력 화면 호환 주소 |
| `/?page=10` 또는 `/?page=11` | 한국어 입력 화면 호환 주소 |

결과에는 `#result=INFP`처럼 MBTI만 기록하여 새로고침·뒤로가기·결과 URL 재방문을 지원합니다. 이름과 나이는 URL, 브라우저 저장소, 서버에 저장하지 않으며 페이지 메모리에만 유지됩니다. 언어 전환과 다시 찾기에서는 입력이 유지되고, 새로고침하면 이름과 나이는 초기화됩니다.

## 디자인과 원본 파일 대응

실제 저장소의 **중국어 입력은 01번, 한국어 입력은 11번**입니다. 10번은 중국어 김단희 결과입니다. 요청의 기본 한국어 진입 의도를 반영해 11번 디자인을 기본으로 사용했습니다.

로고, 커튼 배경, CHOICE 타이틀, 배우 사진, 손글씨와 결과 레이아웃은 제공된 디자인 원본을 그대로 활용했습니다. 입력 폼은 실제 HTML 입력·라디오 버튼으로 구현했고, 이미지 안의 언어 전환·저장 영역에는 키보드로도 동작하는 실제 버튼이 대응합니다. 결과 하단에는 다시 찾기, 언어 전환, 접근 가능한 배우 프로필 텍스트를 추가했습니다. 한국어 폼의 나이 항목은 원본의 `年龄` 대신 `나이`로 표기했습니다. 한국어 메인 상단의 중국어 장식 문구는 디자인 원본대로 유지했습니다.

원본 크기는 813×2459px입니다. 화면은 모바일 너비에 맞춰 비율을 유지하며 데스크톱에서는 최대 540px로 표시됩니다. 화면용 이미지는 WebP로 최적화했고, 저장할 때는 PNG 원본을 사용합니다. 원본 디자인 글자를 수정하려면 해당 원본 이미지와 `src/data.js`의 접근성용 텍스트를 함께 갱신해야 합니다.

배우 식별은 사진 속 얼굴 추정이 아니라 이미지에 인쇄된 이름을 기준으로 대조했습니다.

| 배우 | 중국어 이미지 | 한국어 이미지 | 배우 프로필 MBTI | 이 배우와 매칭되는 방문자 MBTI |
| --- | --- | --- | --- | --- |
| 오진욱 / Oh Jinwook | 02 | 12 | ENFJ | ISFJ, ESFJ |
| 김종민 / Kim Jongmin | 03 | 13 | INFP | ENFJ |
| 김종훈 / Kim Jonghun | 04 | 14 | ENFP | INFJ, ISTP |
| 한민성 / Han Minseong | 05 | 15 | ISTP | ISTJ, ESTP |
| 김준형 / Kim Junhyeong | 06 | 16 | E(I)NFJ | ENTP, ENFP |
| 남충화 / Nam Chunghwa | 07 | 17 | ENTJ | INTP, ESTJ |
| 장노아 / Jang Noa | 08 | 18 | INTP | ENTJ |
| 조동환 / Jo Donghwan | 09 | 19 | ENFP | INTJ, ESFP |
| 김단희 / Kim Danhee | 10 | 20 | ENFJ | INFP, ISFP |

**매칭 규칙의 기준은 `docs/match.md`입니다.** 배우 본인의 MBTI와 방문자의 매칭 MBTI는 서로 다릅니다. 이름은 개인화 문구에 사용하고 나이는 입력 유효성을 검사하며, 문서에 없는 이름·나이별 가중치나 임의의 매칭 규칙은 추가하지 않았습니다.

## 결과 저장

- 결과 화면에서 `결과 이미지 저장` / `保存结果图片`을 누릅니다.
- 파일 공유를 지원하는 모바일 브라우저에서는 PNG 파일을 OS 공유 창으로 전달합니다. 공유 창에서 지원되는 사진 저장/파일 저장 기능을 선택할 수 있습니다.
- 공유를 지원하지 않거나 거부하는 브라우저에서는 PNG 다운로드와 이미지 미리보기를 제공합니다. 미리보기 이미지를 길게 눌러 저장할 수도 있습니다.
- PNG는 813×2459px의 해당 언어 결과 전체 원본이며, 파일 이름에 배우·언어를 포함합니다.
- 사용자 입력 정보는 다운로드 이미지에 합성하지 않습니다. 원본 디자인을 그대로 저장합니다.
- 실제 모바일 OS 공유 창과 사진 앱 저장은 HTTPS 배포 후 실기기로 최종 확인해야 합니다. 브라우저는 사용자의 선택 없이 사진 앱에 직접 저장할 수 없습니다.

## 검증

```sh
pnpm install --frozen-lockfile
pnpm exec playwright install chromium webkit
pnpm run test:e2e
```

`npm install` 및 `npx playwright install chromium webkit`으로도 설치할 수 있습니다. Playwright는 개발 테스트 용도로만 사용하며 런타임 의존성은 없습니다.

검증한 항목:

- `docs/match.md` 16개 규칙 및 9명 배우의 양 언어 이미지 대응
- 한국어·중국어 총 32개 입력→결과 흐름
- 이름/나이 검증, 언어 전환, 뒤로가기/앞으로가기, 다시 찾기, 새로고침
- 320, 375, 390, 430, 768, 1440px에서 가로 넘침 없음
- 다운로드 PNG와 원본 파일의 바이트 일치
- 저장 미리보기 열기/닫기, 파일 다운로드 실패 후 재시도
- 모바일 파일 공유 API 전달/취소 (OS 공유 창은 모킹)
- Chromium 및 모바일 WebKit 렌더링·매칭, JavaScript 오류 없음

브라우저 검증은 빌드된 `dist/`에 대해 실행되며 스크린샷은 `test-results/`에 저장됩니다.

## 파일 구조

```text
src/app.js          입력/결과/언어/저장 동작
src/data.js         배우 프로필 및 방문자 MBTI 매핑
src/i18n.js         한국어·중국어 UI 문구
src/style.css       반응형 입력 UI와 동작 영역
public/assets/     화면용 WebP 및 로고
docs/              디자인 PNG 원본과 match.md
scripts/build.mjs  정적 배포 파일 및 원본 PNG 복사
scripts/serve.mjs  로컬 개발/미리보기 서버
tests/             문서 매핑 검사와 브라우저 검증
```
